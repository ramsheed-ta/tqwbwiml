How to use Quran website

📖 ഖുർആൻ വെബ്‌സൈറ്റ് ഉപയോഗിക്കുന്ന വിധം

🖥️ GUI (Graphical User Interface):
വെബ്‌സൈറ്റിലെ മെനുകൾ, ബട്ടണുകൾ, ഐക്കണുകൾ എന്നിവ ഉപയോഗിച്ച് വിവിധ ഫീച്ചറുകൾ എളുപ്പത്തിൽ ഉപയോഗിക്കാം.

മെനു & സെറ്റിംഗ്‌സ്:

📚 Surah Order:
ഖുർആൻ ക്രമത്തിലോ, അവതരണ ക്രമത്തിലോ (Revelation Order) വായിക്കാം.
🔤 Languages:
മലയാളം, ഇംഗ്ലീഷ്, ഹിന്ദി ഭാഷകളിലെ വാക്ക്-പ്രതി-വാക്ക് (Word-by-word) അർത്ഥവും വിവർത്തനവും തിരഞ്ഞെടുക്കാം.
🔠 Font Size:
- / + അമർത്തി അക്ഷരങ്ങളുടെ വലിപ്പം കൂട്ടാം/കുറയ്ക്കാം.
🔍 Search - പദങ്ങൾ തിരയാൻ:
സെറ്റിംഗ്സിലെ സെർച്ച് ബാർ ഉപയോഗിച്ച് Arabic, Malayalam, English, Hindi യിൽ ഉള്ള ഏത് പദങ്ങളും വേഗത്തിൽ തിരയാം.
📖 Word Meaning:
ഓരോ അറബി വാക്കിനും താഴെയായി അതിന്റെ അർത്ഥം കാണാം.
✅ Ayah - ഖുർആൻ മാത്രം വായിക്കാൻ:
സെറ്റിംഗ്സിൽ Ayah ഓപ്ഷനിൽ ഗ്രീൻ ടിക്ക് ചെയ്താൽ, അർത്ഥങ്ങൾ ഒഴിവാക്കി 'ഖുർആൻ ആയത്തുകൾ മാത്രം' വ്യക്തമായി വായിക്കാം.
💡 Single Tap:
ആയത്തിലെ ഏതെങ്കിലും വാക്കിൽ തൊട്ടാൽ, ആ വാക്കിന്റെ അർത്ഥം ഏത് ഭാഷയിൽ വേണം എന്ന് തിരഞ്ഞെടുക്കാം.
🔢 Double Tap:
പേജിൽ എവിടെയും ഡബിൾ ടാപ്പ് ചെയ്താൽ 'Go to Ayah' ഓപ്ഷൻ വരും. ആയത്ത് നമ്പർ സെലക്ട് ചെയ്ത് നേരിട്ട് പോകാം.
🔖 Last Read - അവസാനം വായിച്ചത്:
മുകളിൽ കാണുന്ന സൂറത്തിന്റെ പേരും ആയത്ത് നമ്പറും (ഉദാ: 96:1) അമർത്തിയാൽ അവസാനം വായിച്ചു നിർത്തിയ ഭാഗത്തേക്ക് പോകാം.
🔼🔽 Change Ayahs:
Up/Down ആരോ ബട്ടണുകൾ ഉപയോഗിക്കാം.
↗️ Share:
ഏതൊരു ആയത്തും വാട്ട്‌സ്ആപ്പിലോ മറ്റ് ആപ്പുകളിലോ ഷെയർ ചെയ്യാൻ Share ഐക്കൺ അമർത്താം.

📖 How to Use the Quran Website

🖥️ GUI (Graphical User Interface):
Easily use different features of the website through menus, buttons, and icons.

Menu & Settings:

📚 Surah Order:
Read the Quran in the standard Quran order or in the order of revelation (Revelation Order).
🔤 Languages:
Select word-by-word meanings and translations in Malayalam, English, and Hindi.
🔠 Font Size:
Use the – / + buttons to decrease or increase the font size.
🔍 Search – Find Words:
Use the search bar in Settings to quickly search for any word in Arabic, Malayalam, English, or Hindi.
📖 Word Meaning:
View the meaning of each Arabic word directly below it.
✅ Ayah – Read Only the Quran:
Enable the green tick for the Ayah option in Settings to read only the Quranic verses without translations or meanings.
💡 Single Tap:
Tap any word in an ayah to choose the language in which you want to see its meaning.
🔢 Double Tap:
Double-tap anywhere on the page to display the Go to Ayah option. Select an ayah number to navigate directly to it.
🔖 Last Read – Resume Reading:
Tap the Surah name and ayah number displayed at the top (e.g., 96:1) to return to the last reading position.
🔼🔽 Change Ayahs:
Use the Up/Down arrow buttons to navigate between ayahs.
↗️ Share:
Tap the Share icon to share any ayah via WhatsApp or other apps.

Other Information – Footer / Info:

🔍 Sources & Credits: View the sources of the information used on the website.
💬 Feedback: Send comments, suggestions, or feedback.
🔄 Last Updated: View the date when the website was last updated.

📖 क़ुरआन वेबसाइट का उपयोग कैसे करें

🖥️ GUI (Graphical User Interface):
वेबसाइट पर मौजूद मेनू, बटन और आइकन का उपयोग करके यूज़र विभिन्न फीचर्स को आसानी से इस्तेमाल कर सकता है।

मेनू और सेटिंग्स:

📚 Surah Order:
यूज़र क़ुरआन के क्रम में या नुज़ूल के क्रम (Revelation Order) में पढ़ सकता है।
🔤 Languages:
यूज़र मलयालम, अंग्रेजी, हिंदी भाषाओं में शब्द-दर-शब्द (Word-by-word) अर्थ और अनुवाद चुन सकता है।
🔠 Font Size:
- / + दबाकर अक्षरों का साइज़ बढ़ा/घटा सकता है।
🔍 Search - शब्द खोजने के लिए:
सेटिंग्स में सर्च बार का उपयोग करके Arabic, Malayalam, English, Hindi में किसी भी शब्द को जल्दी खोज सकता है।
📖 Word Meaning:
हर अरबी शब्द के नीचे उसका अर्थ देख सकता है।
✅ Ayah - सिर्फ क़ुरआन पढ़ने के लिए:
सेटिंग्स में Ayah ऑप्शन पर ग्रीन टिक करने से, मतलब हटाकर 'सिर्फ क़ुरआन की आयतें ही' साफ़ तौर पर पढ़ सकता है।
💡 Single Tap:
आयत के किसी भी शब्द पर टैप करने से, यूज़र उस शब्द का अर्थ किस भाषा में चाहिए यह चुन सकता है।
🔢 Double Tap:
पेज पर कहीं भी डबल टैप करने से 'Go to Ayah' ऑप्शन आएगा। आयत नंबर सेलेक्ट करके सीधे जा सकता है।
🔖 Last Read - आख़िरी बार पढ़ा हुआ:
ऊपर दिख रहे सूरह के नाम और आयत नंबर (जैसे: 96:1) पर क्लिक करने से यूज़र आख़िरी बार पढ़े हुए हिस्से पर जा सकता है।
🔼🔽 Change Ayahs:
Up/Down एरो बटन का उपयोग कर सकता है।
↗️ Share:
किसी भी आयत को WhatsApp या दूसरे ऐप्स पर शेयर करने के लिए Share आइकन दबा सकता है।

Privacy & Terms
Privacy
About this website
Tadabbur Quran is a free, non-commercial website for studying the Quran word by word, with meanings in Malayalam, English and Hindi. It is an independent project. It uses the Quran Foundation API (the Quran Foundation also runs Quran.com and QuranReflect) and is not an official app of the Quran Foundation, QuranEnc.com or Al Quran Cloud.
Services used
Loading this page initiates connections to Vercel and Cloudflare for content delivery. Vercel (hosting), Cloudflare (which passes requests to the Quran Foundation API), the Quran Foundation, QuranEnc.com, Al Quran Cloud and Google Fonts are used to load the website, the text, the translations and the fonts. Each service has its own privacy policy, for example: Vercel, Cloudflare, Google Fonts.
Saved on the user's browser
The user's settings (such as text size, languages and display options) and the user's Last read position are saved only in the user's own browser. They stay until the user clears their browser data.
What this site acquire
There is no sign-in and no advertising. This site does not ask for the user's name, email address or location, and does not set cookies of its own.
Feedback emails
If a user sends feedback by email, this site receives the user's email address and message. They are used only to reply and to fix problems, and are kept only as long as needed for that. tqwbwiml.feedback@gmail.com
Security
Connections use HTTPS. The credentials used for the Quran Foundation API are kept on the server side and are never placed in the web page.
Changes and contact
This page may be updated. The latest update date and notable changes are listed on the Last updated page. Questions: tqwbwiml.feedback@gmail.com
